# Freelancer Carrier & Endgame Mod

A single-player endgame mod for **Freelancer: HD Edition**:
- player-owned mobile carrier bases;
- AI crew and wingmen with a voice copilot;
- ambushes earned from the game's own patrol data;
- a player-driven faction-influence endgame.

It stays vanilla-faithful: same map, factions and campaign.

**Status:** being built autonomously. See `docs/plan/BUILD_PLAN.md` and `state/BUILD_STATE.md`.

This repository contains **only original code, data definitions and generators**. It ships no Freelancer or HD Edition game files: game data is read from your own local installation at deploy time.
