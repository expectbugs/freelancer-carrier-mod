# G1: Wave 1 gate procedure

- **Type:** gate (run by the orchestrator; helpers may be spawned for long runs)
- **Wave:** end of Wave 1
- **Depends on:** W1-PLATFORM, W1-CORE, W1-WORLD, W1-SPAWN, W1-UI, W1-DATA, W1-INVENTORY, W1-CARRIER-DESIGN, W1-HARNESS, W1-SIDECAR, each `MERGED` or `DEGRADED` → **Unblocks:** ARCH-1, then Wave 2

## Goal

Prove, with recorded evidence, that the platform is solid enough to build carrier features on:

- everything merged builds;
- every host test passes;
- every Wave-1 in-game scenario passes on more than one lane;
- the game survives a 30-minute soak with no crash and no new error spew.

## Procedure

1. **Freeze.** Confirm no Wave-1 agent is running and every `DEFERRED` scenario has run in the integration pass. `git checkout main` (the main checkout is authoritative; never rewrite history). Record the HEAD SHA.
2. **CI:** `harness/ci.sh --full --lanes 2`. Copy `summary.md` to `state/gates/G1-ci.md`. On failure, open `FIX-<n>` packages (brief in `state/briefs/FIX-<n>.md`, CONVENTIONS §10), run the review loop, merge, and restart at step 1.
3. **Regression:** `harness/suite.sh regression --lanes 2`.
   - Copy `report.md` to `state/gates/G1-regression.md`.
   - Resolve pending vision checks: view each image and record a verdict (`scenario.sh finalize`).
4. **Soak:** `harness/soak/soak.sh --hours 0.5 --lanes 2 --seed <n> --mix harness/soak/mixes/w1.yaml`. Copy `report.md` to `state/gates/G1-soak.md`.
   - The mix covers: platform events, the persistence round-trip, the spawn soak, the inventory round-trip, UI kit screenshots, and data boot. Weights: equal.
5. **ENGINE_FACTS:** append any new VERIFIED facts from Wave-1 reports (`state/reports/`), with evidence paths.
6. **Write `state/gates/G1.md`:** HEAD SHA, each criterion's PASS/FAIL with evidence links (local paths are fine), the degraded list, and decisions taken during the gate.
7. **On PASS:**
   1. Set the gate to `PASSED` in the ledger's Gates table. Never touch line 1 except for deliberate status changes (CONVENTIONS §10).
   2. Tag `g1` (annotated) and push `main` plus the tag to GitHub.
   3. Push notification: "Gate G1 passed: platform ready (N scenarios, 30-min soak clean)".
   4. Start ARCH-1.
8. **On FAIL:**
   1. Open `FIX-*` packages per failing criterion; re-run from step 1 after the merges.
   2. After 3 failed fix rounds on the same criterion, apply AUTONOMY §4 (fallback, then degrade), and list the failing scenarios in `state/QUARANTINE.md` with the FIX ID. `ci.sh` then reports them as `SKIP(quarantined)`.
   3. Record a gate exception in `state/gates/G1.md`, with the reason and evidence, notify, and proceed.
